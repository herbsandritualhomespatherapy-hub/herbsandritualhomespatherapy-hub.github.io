# Herbs & Ritual Home Spa Website 🌿

Welcome to the official repository for **Herbs & Ritual**, a home service wellness and spa business that specializes in **therapeutic massage, organic botanical baths, and ritual-based wellness experiences**.

---

## 🌿 About This Project

This repository contains the full **HTML website** for Herbs & Ritual, including:

- **About Us** – Our story, mission, philosophy, and core values  
- **Signature Packages** – Therapeutic home massage with organic oils and free gifts  
- **Regular Massage Services** – Classic Swedish, Thai, Shiatsu, Hotstone, and more  
- **Hair Removal & Other Services** – Foot spa, body scrub, ear candling, and more  
- **100% Organic Botanical Bath Soaks** – Solo or wellness bundle packs  
- **Connect With Us** – Contact information and social links  
- **Book Your Wellness Ritual** – Easy booking button linking to Messenger/WhatsApp  

The website features a **dark sage green theme**, clean typography, and a responsive layout for **mobile and desktop users**.  

---

## 🎨 Features

- Fully **responsive HTML website**  
- **Dark sage green color theme** for a calming, wellness-inspired aesthetic  
- **Signature Massage & Service Menu** tables  
- **Botanical Bath Soaks** section with benefits  
- **Connect & Book Now** sections with clickable links
